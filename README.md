# Piercer Crypto Wallet, Staking & Airdrop Tracker

Controle multi-carteiras (ETH, SOL, BTC, Arbitrum, Base), simulador de APY/Staking e checklist de Airdrops

## Funcionalidades

- **Seções principais**: Carteiras & Redes (USD), Simulador Staking / DeFi APY, Rastreador de Airdrops & Testnets
- **Ações disponíveis**: + Wallet, + Airdrop
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8136`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8136`.
